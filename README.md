# 決算画像ジェネレーター v62

- 表示期間のデフォルトは20期間（データが20未満なら全期間）
- 表示期間の最大値は四半期・年度とも30期間（データが30未満ならその件数）
- v61のGoogle Sheets空シート安全読み込み、1:1デフォルト、年度/四半期分離、企業マスター機能を継承


## v64: 外国通貨の「億」表示と入力単位ルール
- USD/EUR/CNY/DKK/KRW/NOK/SEK/CHF/TWD/HKD に「億通貨」表示を追加。
- 外国通貨の現地通貨表示は「億通貨」をデフォルトに変更。
- マスター内の財務数値は、特記がない限り百万通貨単位として解釈します（JPY=百万円、USD=百万ドル、EUR=百万ユーロ、CNY=百万元など）。
- 例: USDの入力 130,497 は 130,497百万ドル = 1,304.97億ドル = 130.497×10億ドル。

## v66
- Google Sheets / Excel マスターの `設定` シートにある `display_unit` を、グラフ生成時だけでなくサイドバーUIの初期値にも反映。
- 例: `input_currency=USD`, `display_unit=億ドル` で「現地通貨 / 億ドル」が自動選択。
- 円換算を使う場合は `display_unit=億円` などJPY表示単位を指定すると「円換算」を自動選択。
- 対応単位: JPY=百万円/億円/十億円/兆円、外貨=百万/億/10億の各通貨単位。
- 財務入力値は特記がない限り百万通貨単位として扱う。
