# 決算画像ジェネレーター v57

## v57
- Googleスプレッドシートを「1社1マスター」としてURLから直接読み込み
- シート構成: 設定 / 会社全体 / セグメント売上高 / セグメント利益 / 受注 / ARR
- 「設定」シートから会社名、通貨、表示単位、サブタイトル、カラーコードを一括反映
- Google Sheetsは閲覧可能な共有設定が必要（編集権限は不要）
- 「Google Sheetsから読み込む」を押すと最新状態を再取得
- Excelマスター (.xlsx) と従来のタブ別CSVも継続対応

## Google Sheets運用
同梱の `company_master_template.xlsx` をGoogle Driveへアップロードし、Googleスプレッドシートとして開いてください。共有設定を「リンクを知っている全員が閲覧可」等にし、そのURLをアプリへ貼り付けます。
